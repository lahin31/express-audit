# SQL001 — SQL Injection Risk

| Property   | Value          |
|------------|----------------|
| **ID**     | SQL001         |
| **Severity** | 🔴 Critical  |
| **Category** | SQL Security |
| **Detector** | AST          |

## Description

A raw SQL query is constructed by concatenating or interpolating user-controlled values from `req.body`, `req.query`, or `req.params` directly into the query string.

## Why It Matters

SQL injection is consistently ranked in the OWASP Top 10. An attacker can manipulate the query to bypass authentication, exfiltrate the entire database, modify or delete data, and in some database configurations execute OS commands.

## Vulnerable Examples

```typescript
// ❌ Template literal interpolation
app.get('/users', async (req, res) => {
  const users = await db.query(
    `SELECT * FROM users WHERE name = '${req.query.name}'`
  );
  res.json(users);
});

// ❌ String concatenation
app.get('/user/:id', async (req, res) => {
  const user = await db.query(
    'SELECT * FROM users WHERE id = ' + req.params.id
  );
  res.json(user);
});
```

An attacker querying `?name='; DROP TABLE users; --` can destroy the database.

## Secure Examples

```typescript
// ✅ Parameterised query (mysql2, pg, sqlite3)
app.get('/users', async (req, res) => {
  const users = await db.query(
    'SELECT * FROM users WHERE name = ?',
    [req.query.name]
  );
  res.json(users);
});

// ✅ Prepared statement (pg with node-postgres)
app.get('/user/:id', async (req, res) => {
  const result = await pool.query(
    'SELECT id, email FROM users WHERE id = $1',
    [req.params.id]
  );
  res.json(result.rows[0] ?? null);
});

// ✅ Prisma ORM (safe by default)
app.get('/user/:id', async (req, res) => {
  const user = await prisma.user.findUnique({
    where: { id: parseInt(req.params.id) },
    select: { id: true, email: true },
  });
  res.json(user);
});
```

## Remediation

1. **Never** concatenate user input into SQL strings.
2. Use parameterised queries or prepared statements — every mainstream Node.js database driver supports them.
3. Prefer an ORM (Prisma, TypeORM, Drizzle) for routine queries.
4. Validate and parse user input before it reaches the data layer (e.g. `parseInt`, Zod schema).
