# CSP001 — Missing Content Security Policy

| Property     | Value         |
|--------------|---------------|
| **ID**       | CSP001        |
| **Severity** | 📋 Medium    |
| **Category** | HTTP Security |
| **Detector** | AST           |

## Description

No Content Security Policy (CSP) header is configured. CSP is the primary browser-level defence against Cross-Site Scripting (XSS).

## Why It Matters

Without CSP, the browser will execute any script on the page — including attacker-injected scripts from XSS vulnerabilities. CSP restricts which sources scripts, styles, and other resources may load from, turning a full XSS exploit into a blocked console error.

## Vulnerable Example

```typescript
// ❌ No CSP configured — full XSS execution
app.use(helmet({ contentSecurityPolicy: false }));
```

## Secure Examples

```typescript
// ✅ Using helmet default CSP
app.use(helmet());

// ✅ Strict, custom policy
app.use(
  helmet.contentSecurityPolicy({
    directives: {
      defaultSrc: ["'self'"],
      scriptSrc: ["'self'"],
      styleSrc: ["'self'", "'unsafe-inline'"],
      imgSrc: ["'self'", 'data:', 'https:'],
      connectSrc: ["'self'"],
      fontSrc: ["'self'"],
      objectSrc: ["'none'"],
      mediaSrc: ["'self'"],
      frameSrc: ["'none'"],
      upgradeInsecureRequests: [],
      baseUri: ["'self'"],
      formAction: ["'self'"],
    },
  }),
);

// ✅ Using a nonce-based CSP for inline scripts (most secure)
app.use((req, res, next) => {
  res.locals.nonce = crypto.randomBytes(16).toString('base64');
  next();
});
app.use(
  helmet.contentSecurityPolicy({
    directives: {
      scriptSrc: ["'self'", (req, res) => `'nonce-${(res as any).locals.nonce}'`],
    },
  }),
);
```

## Remediation

1. Install `helmet` and call `app.use(helmet())` — this enables CSP with sensible defaults.
2. Progressively tighten your CSP using `Content-Security-Policy-Report-Only` with a `report-uri` before enforcing.
3. Avoid `'unsafe-inline'` and `'unsafe-eval'` in `scriptSrc`.
4. Use nonces or hashes for unavoidable inline scripts.
